# 小红帽｜您的一站式达人撮合伙伴

面向中国中小商家的海外达人合作工具。当前场景：美妆 · 美国市场 · TikTok · 英语 · 美元。

填写需求 → 查找达人 → 确认询价名单与预算 → 编辑并下载合作材料。

默认提供4位真实创作者的公开资料、作品/商务入口、来源和核对日期（2026-10-21）；另有独立的12位虚构达人演示库。两者不会混入同一名单。

真实库可搜索、查看相似人选、记录商家收到的报价、整理询价与Brief。未知价格不会冒充0美元；已知报价超过预算会拦截。公开UGC制作费不等于达人账号发布费。数据来自创作者自发布网页，尚未获平台或本人核验，近期表现、受众、账号发布、档期和授权均待确认。

纯前端HTML，无需API key、后端或安装依赖。直接打开index.html，或访问 https://guoyangc15-creator.github.io/Red-riding-Hood/ 。草稿仅保存在本浏览器，建议下载备份。

未接入TikTok One或实时大模型；没有自动翻译或真实邮件服务。所有发送均为模拟，不实际投递。真实联系由商家自行完成。

详见[真实资料与使用说明](docs/真实达人公开资料与使用说明.md)及[来源台账](data/creators-public.json)。规则测试位于tests，下载行为在自动测试中使用mock，真实浏览器检查单独记录。

仅用于 2027 校园招聘，未经许可不得用于其他用途。
