用于 AI coding 作品说明。独立规则 Demo，不属于小红书官方产品。

- 在线入口：`https://guoyangc15-creator.github.io/Red-riding-Hood/v3/`
- 本地运行：双击 `index.html`。无依赖、API key 或后端。
- 原 TikTok 版继续保留在仓库根目录，原数据不混入 V3。
- 首次演示建议点击“重置演示”并确认。新项目可从“新建空白项目”开始。

## 最短演示路径

工作台 → 第一条笔记诊断 → 查看图片证据 → 确认诊断 → 准备计划 → 改预算1300触发拦截 → 改回300 → 返回诊断撤销授权 → 查看准备状态阻断。

再看第三条高互动但产品信息不足的笔记，说明为什么本轮不投入。第二条是原创视频脚本分镜，不是真实拍摄视频，可模拟优化后重新评估。

## 文件

- `index.html`：完整纯前端源码与运行文件。
- `docs/product.md`：产品设计、用户流程、规则、公开来源与验证方案。
- `docs/technical.md`：复用、状态、预算、编辑导出与模型扩展边界。
- `docs/interview.md`：90秒介绍、3分钟点击路径、10个业务追问。
- `docs/tests.md`：实际测试与限制。
- `docs/flow.svg`：用户流程图，标注“用于 AI coding 作品说明”。
- `tests/regression.cjs`、`tests/results.txt`：可重复测试与结果。

交付 ZIP 另含截图、原版 HTML 备份及源码。网站文件无需安装 Node；仅重跑自动检查时需要 Node 和 jsdom。

## 必须如实说明

6位达人、3条合作内容、价格、指标、授权状态均为虚构。公开研究仅支持机制理解。运行时是规则与模板，无 LLM、视频理解、平台同步、真实授权核验、发送、广告创建或消耗。浏览器保存为本地存储，不是云数据库。

预算统一人民币，合作费、媒体测试、追加授权、其他预留分别管理。无行业均价或效果承诺。页面支持复制和下载最后编辑的内容；字段变更后须核对草稿。清除浏览器数据会丢失本地记录，请及时导出。
